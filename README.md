<!-- 公開したら、上の「ユーザー名」を自分のGitHubユーザー名に書き換える（README.md の鉛筆マークから編集できる） -->

- セクションを選ぶと、ストックからランダムに10問が出題されます（5問・20問にも変更できます）。
- 一度出た問題は、そのセクションを一周するまで出ません。選択肢の順番は毎回シャッフルされます。
- 採点後は「同じ範囲で次の10問」「間違えた問題を復習」「別のセクションへ」のどれかを選んで続けられます。
- 「まとめて解く」と「1問ずつ（すぐに答え合わせ）」を切り替えられます。
- 出題履歴・正答率・復習リストは、そのブラウザに保存されます（スマホとPCでは記録が別になります）。

## 公開する手順（GitHub Pages）

### 準備
`teppeki-quiz.zip` を解凍しておく。
中身：`index.html` ／ `questions.js` ／ `README.md` ／ `.nojekyll` ／ `kit/` フォルダ

### 1. リポジトリを作る
GitHubで「New repository」を押す
- Repository name：`teppeki-quiz`
- **Public** を選択（無料プランでPagesを使うにはPublicが必要）
- →「Create repository」

### 2. ファイルをアップロードする
作ったリポジトリの画面で「uploading an existing file」を押す
→ 解凍したフォルダの **中身をすべて**（`kit` フォルダごと）ドラッグ
→「Commit changes」

> `.nojekyll` は隠しファイルなので見えないことがあります。
> Mac：Finderで `Command + Shift + .`（ピリオド）を押すと表示されます。
> Windows：エクスプローラーの「表示」→「隠しファイル」にチェックを入れると表示されます。

### 3. Pagesを有効にする
Settings → 左メニューの **Pages**
- Source：**Deploy from a branch**
- Branch：**main** ／ フォルダ：**/(root)**
- →「Save」

### 4. 開く
1〜2分待ってから、次のURLにアクセスする
`https://ユーザー名.github.io/teppeki-quiz/`
（「ユーザー名」は自分のGitHubユーザー名に置き換える）

**開けたら、このREADMEの一番上のリンクも書き換えておく**と、リポジトリのトップからすぐ飛べます。

## 問題を追加する・作り直す（Claudeにまとめて作ってもらう）

1. `kit/templates/wordlist_template.csv` を開き、自分の鉄壁を見ながら「section, word, pos, meaning」を入力する
   （見出し語と意味だけで十分。例文などを書き写す必要はありません）
2. Claudeに **このzip** と **入力した単語リスト** を添付して、次のように送る
   ```
   kit/SKILL.md の手順どおりに、単語リストの全セクション分の問題バンクを作って、
   questions.js を差し替えた teppeki-quiz.zip を返してください。
   GitHubのユーザー名は ○○○ です。
   ```
3. 返ってきたzipを解凍し、GitHubで同じように「Add file → Upload files」から上書きアップロードする
   → 数分でサイトに反映されます

### 1回で全セクションを作りきりたいとき
`kit/一括作成プロンプト.md` の枠内をコピーし、このzipと一緒にClaudeに送ってください。単語リストがなくても動きます（その場合のセクション構成はオリジナルになります）。

### 手で1問だけ直したいとき
`questions.js` を開き、該当する問題の `{ }` の中を書き換える。
- `options`：選択肢4つ（表示順は自動でシャッフルされる）
- `answer`：正解が `options` の何番目か（**0から数える**。1つ目なら0）
- `wrong`：誤答の語ごとの「入らない理由」

GitHub上でファイルを開き、鉛筆マークから直接編集してもOKです。

## 注意
- 単語リスト（`wordlist.csv`）は **アップロードしないでください**。Publicのリポジトリは誰でも見られるため、市販の教材の収録語一覧を公開することになってしまいます。サイトに必要なのは `questions.js`（オリジナルの例文で作った問題）だけです。
- `questions.js` に最初から入っている「サンプル」の3問は動作確認用です。本番の問題を作ると置き換わります。
